# Project description (500-character limit)

**Draft (474 characters including spaces):**

> Pocket Task is an AI assistant you trigger with one simple physical control: ask a question aloud and hear the answer, without opening apps. My working prototype uses an Arduino Uno as a USB trigger for a laptop app that turns speech into text with whisper.cpp, answers with the existing Qwen3.5 0.8B model running locally, and replies with text-to-speech. It includes a working student mode for learning. My next goal is a smaller, wrist-worn version, still in development.
